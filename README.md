### 🚀 Highlighted Projects

#### 1. [Signova — AI Sign Language & Regional Language Bridge](https://github.com/purvgandhi/signova)
*Applied AI/ML · Computer Vision · FastAPI WebSocket · Local SLM Grounding · Offline PWA*
* **What it does:** Real-time dual-hand tracking and gesture classification platform converting Indian Sign Language into natural sentences and translating them into 5 Indian languages (Hindi, Marathi, Gujarati, Tamil, Telugu) with speech synthesis.
* **Architecture:** 126-feature MediaPipe landmark extraction feeding a 2-layer stacked Bidirectional LSTM (52 gesture classes) with a Finite State Machine (FSM) temporal consensus filter and local Small Language Model (SLM) grammar grounding.
* **Quality & Reliability:** Sub-50ms inference latency, 109 automated unit/E2E test suite passing, and offline-first PWA caching.
* **Tech:** Python, TensorFlow, FastAPI, WebSockets, JavaScript, Web Speech API.

#### 2. [StackShield — Static Codebase Analyzer for Java](https://github.com/purvgandhi/stackshield)
*Java · AST Parsing · Static Code Analysis · Security Auditing · Docker*
* **What it does:** A developer tooling engine that performs deterministic static analysis on Java codebases to identify security vulnerabilities, calculate cyclomatic complexity, and detect version upgrade regressions.
* **Architecture:** Multi-threaded abstract syntax tree (AST) parser with modular rule-matching engines and containerized deployment for automated CI/CD integration.
* **Tech:** Java 17+, Maven, Docker, Shell.

#### 3. [InsightFlow — FinTech Revenue & Payments Analytics](https://github.com/purvgandhi/InsightFlow)
*Python · PostgreSQL · Pandas · Analytical SQL · Interactive Dashboard*
* **What it does:** End-to-end payments intelligence dashboard that reconciles multi-currency transaction and refund ledgers, detects chargeback anomalies, and serves executive KPIs.
* **Architecture:** Pandas data ingestion and cleaning pipeline feeding a normalized PostgreSQL schema with complex window-function queries delivering sub-100ms dashboard aggregations.
* **Tech:** Python, PostgreSQL, Pandas, JavaScript, HTML/CSS.

#### 4. [DocMind — Document Intelligence & RAG System](https://github.com/purvgandhi/DocMind)
*Python · RAG · Semantic Retrieval · Natural Language Processing*
* **What it does:** Retrieval-Augmented Generation (RAG) platform that ingests unstructured technical documents, generates semantic vector embeddings, and delivers source-grounded, unhallucinated answers.
* **Architecture:** Modular sliding-window text chunking, cosine-similarity retrieval, prompt grounding guardrails, and an automated retrieval evaluation harness.
* **Tech:** Python, Vector Retrieval, NLP, HTML/JS.

#### 5. [Book Inventory Management REST API](https://github.com/purvgandhi/book-inventory-api)
*Python · FastAPI · SQLAlchemy · Pydantic v2 · Pytest*
* **What it does:** A clean, production-ready inventory microservice providing atomic CRUD operations, full-text search, sales tracking, and real-time revenue accounting.
